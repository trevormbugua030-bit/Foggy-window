# Foggy Window

A small, self-contained fogged-glass scene built with HTML, CSS, vanilla JavaScript, and the Canvas API. Drag with a mouse or touch the glass to clear a path; choose **Reset** to bring the condensation back.

## Run on Linux

Open `index.html` directly in a modern browser, or serve this folder locally:

```sh
python3 -m http.server 8000
```

Then visit <http://localhost:8000>.

The landscape, condensation, and droplets are generated locally in canvas. The page has no build step, framework, backend, or external API.
